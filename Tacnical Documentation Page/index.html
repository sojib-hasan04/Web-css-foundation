Introduction

JavaScript is a lightweight, cross-platform programming language.

It is widely used to develop dynamic and interactive web pages.

console.log("Hello, World!");
Variables

Variables are containers for storing data values in JavaScript.

Here are three keywords to declare variables:

let x = 10;
  • var
  • let
  • const
  • global
  • block
Functions

A JavaScript function is a block of code designed to perform a particular task.

Functions execute when they are called or invoked.

function test() {}
Loops

Loops are handy if you want to run the same code over and over again.

Common loops include for and while loops.

for (let i = 0; i < 5; i++) {}
Objects

Objects are variables that can contain many values.

Values are written as name:value pairs.

const obj = {key: "value"};
